How to get started

  1. Download the installer and open it.
  2. If Windows says “Windows protected your PC”, click More info → Run anyway. That appears because the app isn’t code-signed yet.
  3. Open AI Arcade and click Sign in → Register.
  4. Type the 6-digit code we email you. Can’t find it? Check your spam folder.

The app updates itself — when a new version is out, it asks you to update when you open it.
